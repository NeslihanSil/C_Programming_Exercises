# C_Programming_Exercises

Bu repo temel C programlama alıştırmalarını içerir.  
Yazılım mühendisliği eğitimim sırasında geliştirdiğim temel, öğrenme amaçlı örnek projeler ve alıştırmalar burada yer almaktadır.

## İçerik Başlıkları

**Temel Yapılar**
  - Veri tipleri (int, float, char, double)
  - Değişkenler ve sabitler
  - Operatörler (aritmetik, mantıksal, karşılaştırma)

  **Kontrol Yapıları**
  - if – else koşullu ifadeler
  - switch – case yapısı
  - Döngüler: for, while, do-while

 **Fonksiyonlar**
  - Fonksiyon tanımı ve çağrısı
  - Parametreler ve dönüş değerleri
  - Rekürsif fonksiyonlar

 **Diziler**
  - Tek boyutlu diziler
  - Çok boyutlu diziler (matrisler)
  - Dizilerle temel algoritmalar (arama, sıralama)

  **Pointer (Göstericiler)**
  - Pointer tanımı ve kullanımı
  - Pointer ile diziler
  - Pointer ve fonksiyon ilişkisi

 **String İşlemleri**
  - Karakter dizileri
  - Standart string fonksiyonları (`strlen`, `strcpy`, `strcmp`)

 **Yapılar (struct) ve Birlikler (union)**
  - struct tanımı ve kullanımı
  - union kullanımı
  - typedef ile özel tipler

 **Dosya İşlemleri**
  - Dosya açma, okuma, yazma
  - fgetc, fgets, fprintf, fscanf fonksiyonları

  **Ek Konular**
  - Dinamik bellek yönetimi (`malloc`, `calloc`, `free`)
  - Header dosyaları ve modüler programlama
  - Hata yönetimi ve debug teknikleri
